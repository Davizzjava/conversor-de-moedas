# 💱 Currency Converter

A clean, responsive, and real-time currency converter built with vanilla Web Technologies. This project was developed to demonstrate API integration and DOM manipulation skills.

## 🚀 Live Demo
[Click here to see the project in action](https://Davizzjava.github.io/conversor-de-moedas/)

## 🛠️ Technologies Used
* **HTML5:** Semantic structure.
* **CSS3:** Flexbox, responsive design, and modern UI.
* **JavaScript (Vanilla):** DOM manipulation, Fetch API, and asynchronous data handling.
* **ExchangeRate-API:** Fetching real-time exchange rates.

## 💡 Features
* Real-time conversion between USD, BRL, and EUR.
* Mobile-friendly and fully responsive design.
* Clean and intuitive user interface.
* Error handling for failed API requests.
